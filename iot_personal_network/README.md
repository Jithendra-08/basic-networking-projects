# Simple Networking Projects – Cisco Packet Tracer

This repository contains a collection of simple networking projects and practice labs created using **Cisco Packet Tracer**. These projects are part of my hands-on learning journey in computer networking and focus on understanding how network devices communicate, how networks are configured, and how connectivity is tested.

## 🎯 Purpose

The main purpose of this repository is to practice networking concepts by designing and configuring small network topologies in Cisco Packet Tracer.

I am gradually building my networking knowledge from fundamental concepts toward advanced areas such as **routing, switching, network automation, network security, and AI-powered networking**.

## 🛠️ Tools Used

- **Cisco Packet Tracer**
- Basic Cisco IOS commands
- Networking troubleshooting and connectivity-testing commands

## 📚 Concepts Covered

The projects in this repository may include:

- LAN and basic network topologies
- IP addressing
- Subnetting
- MAC addresses
- ARP
- Switches
- Routers
- Default gateways
- DHCP
- Basic routing
- VLANs and network segmentation
- Client-to-client communication
- Network-to-network communication
- Connectivity testing using `ping`
- Basic network troubleshooting

## 📁 Repository Structure

Each project is organized around a particular networking concept or topology.

Typical project files may include:

```text
Simple-Networking-Projects/
│
├── Project-1/
│   └── network.pkt
│
├── Project-2/
│   └── network.pkt
│
├── Project-3/
│   └── network.pkt
│
├── screenshots/
│
└── README.md
```

The `.pkt` files can be opened using **Cisco Packet Tracer** to view the topology, device configurations, and network setup.

## 🧪 Testing

For the projects, connectivity is tested using tools and commands such as:

```text
ping
ipconfig
arp
```

The tests help verify whether devices can communicate correctly and whether the configured network is functioning as expected.
